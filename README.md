# Sistema de Cadastro de Alunos

Projeto desenvolvido em Python para a disciplina de **Coding**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, ministrada pela docente **Juliana Mafra**, no **Centro Universitário Maurício de Nassau (UNINASSAU)**, em Caruaru, Pernambuco.

## Funcionalidades

O sistema permite:

- Adicionar alunos;
- Listar todos os alunos cadastrados;
- Buscar alunos pelo nome;
- Editar informações de alunos cadastrados;
- Remover alunos;
- Calcular a média geral das notas;
- Salvar os dados dos alunos em um arquivo JSON;
- Reiniciar o sistema sem perder os dados cadastrados.

## Tecnologias utilizadas

- Python;
- JSON;
- Git;
- GitHub.

## Como executar

1. Tenha o Python instalado no computador;
2. Baixe ou clone este repositório;
3. Abra a pasta do projeto;
4. Execute o arquivo `main.py`.

No terminal, utilize:

```bash
python main.py
```
